Discord App (bot)

Written in Python, with addition of discord.py library.

It supports slash commands, and is able to show weather for Gdansk using openweathermap.org. I plan to add scheduling system, that will let user add events to built-in calendar.

I do not plan to making it open-source any time soon, or releasing the bot for public use.


Reactor simulator

Written in Lua, in modded Scrap Mechanic game on Steam.

It will simulate BWR (Boiling Water Reactor) with other auxilary systems, such as turbines and condenser.

I will probably make it open-source on GitHub and I will release it on Steam Workshop. You will need to have Scrap Mechanic in order to actually use this simulator.
